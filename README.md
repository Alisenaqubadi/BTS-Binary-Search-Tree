# Binary Search Tree

This project is part of [The Odin Project](https://www.theodinproject.com/) curriculum. It involves implementing a Binary Search Tree (BST) in JavaScript.

## Features
- Create a balanced binary search tree from an array of data.
- Insert and delete nodes from the tree.
- Traverse the tree in different orders (in-order, pre-order, post-order).
- Check if the tree is balanced.
- Rebalance the tree if it becomes unbalanced.

## Code Features
- **Binary Search Tree Implementation**: The `BTS.js` file contains methods for creating, inserting, deleting, and balancing the tree.
- **Queue Helper**: The `queue.js` file provides a queue implementation to assist with level-order traversal.
- **Interactive Testing**: The `main.js` file allows you to test the tree operations interactively or by modifying the script.
- **Error Handling**: Includes basic error handling for invalid inputs.
- **Modular Design**: Code is organized into separate modules for better readability and maintainability.

## Getting Started

### Prerequisites
- Node.js installed on your system.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Alisenaqubadi/BTS-Binary-Search-Tree.git
   ```
2. Navigate to the project directory:
   ```bash
   cd BTS-Binary-Search-Tree
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Usage
1. Run the application:
   ```bash
   node src/main.js
   ```
2. Follow the prompts or modify the `src/main.js` file to test different tree operations.

## Project Structure
- `src/BTS.js`: Contains the implementation of the Binary Search Tree.
- `src/queue.js`: Helper class for managing queues (used in tree traversal).
- `src/main.js`: Entry point for running and testing the tree implementation.
